цифрового признака транспортного средства.

## Зачем этот репозиторий

Материалы были сданы до стоп-кода по ссылке на Яндекс.Диск: https://disk.yandex.ru/d/cNamjPCdgdhJtA.
Из-за сбоя Яндекс.Диска файлы по этой ссылке могут не скачиваться. Здесь лежит их точная копия,
чтобы эксперты могли открыть материалы.

* Файлы не изменены. Контрольные суммы MD5 ниже совпадают с теми, которые сам Яндекс.Диск показывает
  для сданных файлов (их можно проверить через публичный API диска). Время изменения взято с диска.
* Сданный репозиторий с кодом не трогали: https://github.com/ski11s100/falcon-reid, последний коммит
  29.09.2026 в 02:15 по Москве, до стоп-кода.

## Как проверить, что файлы те же

```bash
md5sum "files/1 Презентация/Агробизнесмены - презентация.pdf"
curl "https://cloud-api.yandex.net/v1/disk/public/resources?public_key=https://disk.yandex.ru/d/cNamjPCdgdhJtA&path=/1%20Презентация/Агробизнесмены%20-%20презентация.pdf"
```

Поле `md5` в ответе диска совпадает с суммой файла здесь.
