КАК ЗАПУСТИТЬ
1. Нужен Docker. С видеокартой NVIDIA:   docker compose up --build
   Без видеокарты:                        docker compose -f docker-compose.yml -f docker-compose.cpu.yml up --build
2. Открыть http://localhost:8000 (API и Swagger: http://localhost:8000/docs).
3. Демонстрационная галерея: python scripts/seed_demo_gallery.py <каталог данных> --url http://localhost:8000
Файлы сдачи для публичного теста лежат в папке submission репозитория. Команда пересборки описана в README, раздел 3.
